# Banana Ball Championship League (BBCL) Data Repository

Standalone repository housing regular season schedules, box scores, standings, and postseason series records for the **Banana Ball Championship League (BBCL)**.

## Directory Structure
- `data/bbcl/{season}.json`: Regular season schedule, points, results, and embedded postseason blocks
- `data/bbcl/postseason.json`: Banana Bowl and tournament postseason records
- `data/bbcl/metadata.json`: Ingestion and update timestamps
- `scripts/scrapeBBCL.js`: 100% self-contained schedule and results generator
